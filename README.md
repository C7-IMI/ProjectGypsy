# ProjectGypsy

A game. The repository is its working home; the engine, target platforms and interface standard are not chosen yet.

## Working rules

This repository runs on a **ProjectPack** — a portable set of standing rules, prompts and checks for AI-assisted
software work — copied from C7NTRY's pack (revision 2.5) on 2026-10-25 and applied here.

- [`AGENTS.md`](./AGENTS.md) — read this first; the entry point for any model working here.
- [`ProjectPack.md`](./ProjectPack.md) — the standing rules, this copy's revision **PG-1**. Parts 1–10 are the
  portable pack and the operator's rules; Part 11 is this repository's overlay.
- [`ProjectPack-NOTES.md`](./ProjectPack-NOTES.md) — how the pack resolves here: placeholders, day-one decisions,
  the check inventory, what is in force, and the §11 mapping.
- [`ProjectPack-ADDENDUM-Interface.md`](./ProjectPack-ADDENDUM-Interface.md) — the interface design and redesign
  rules, **parked and not in force** because this is a game, not a website. It can be restored deliberately.
- [`DEFERRED.md`](./DEFERRED.md) — the work deliberately not done, and what unblocks it.
